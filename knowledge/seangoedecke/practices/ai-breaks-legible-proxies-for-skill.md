# AI breaks the legible proxies fields use to reward skill

When a field's hardest visible signals of expertise become cheap for AI to
produce, those signals stop discriminating who's actually skilled — and the
field has to either wall off human-only competition or find new signals AI
can't counterfeit.

Fields don't reward the real underlying work directly, because it's usually
illegible to outsiders — nobody can judge whether a new mathematical concept
is insightful, or whether a codebase's architecture is sound. Instead they
reward a legible proxy that's hard to fake: solving a famous open problem, or
shipping a meaty side project (an emulator, a toy OS) on your GitHub. The
proxy works only as long as producing it requires the real skill. Once AI can
produce the proxy "the hard way" — solving the puzzle, writing the toy OS —
without needing (or without visibly needing) the underlying capability, the
proxy is Goodharted: it still gets produced, but it no longer measures
anything. Mathematicians organizing around *A Severe Misalignment of AI in
Mathematics* are reacting to exactly this: AI-solved problems don't
demonstrate that new, useful ideas were generated, which was the proof's real
point all along.

Software engineering has the same structure without the prestige economy: we
write code for money, not credentials, but the same collapse is happening to
its informal signals. A side project used to be evidence of skill; now any
such project is assumed vibe-coded, so it carries no signal at all. Stories
about engineers who rewrite a system over a weekend no longer distinguish
anyone, since an AI subscription lets anyone do that. Two responses are
visible in other domains that already went through this (chess engines,
tool-assisted speedruns): silo "AI work" off from "human work" so human-only
competition keeps its meaning, or find legible skills that structurally
resist AI counterfeiting (see `pick-durable-advantages-not-moving-targets` in
this same area for what that second option requires in practice). Either way,
the old proxies are gone, and rebuilding a cultural sense of what to value
takes real work, not nostalgia for the old signals.
