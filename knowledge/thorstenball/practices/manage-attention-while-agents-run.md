# Manage your attention while the agent runs

A practitioner problem Ball flags as one of the few things he's *sure* about: in
the future a lot of code will be written while nobody is watching — more agents,
running longer, kicked off from everywhere. So the live question becomes **where
does your attention go while an agent works, and how do you bring it back when you
need it?**

The failure mode is concrete and personal: he's built up muscle memory to `cmd-tab`
to another window the instant he submits a prompt, then gets stuck on the other
side. (His evergreen analogy is a pre-Docker team that watched Scrubs on a second
monitor while VMs rebuilt, because a bit of light TV in peripheral vision was *less*
distracting than switching windows and losing the thread — but he's clear that
watching Scrubs is "probably not the solution.")

The fix he actually adopted, after the cmd-tab muscle memory bit him: close the
browser window with the private profile, put the phone away, and commit to one of
two things while the agent runs — **either try to figure out the same thing the
agent is figuring out, or do your own separate work** — rather than drifting into
distraction. That swap alone produced "two incredibly productive days." The
discipline isn't about staring at the agent; it's about refusing the reflexive
context-switch into nothing.
