# Practices — thorstenball

How Thorsten Ball (author of Amp's canonical *How to Build an Agent*, the
line-by-line harness reference the corpus's builder cluster repeatedly cites)
thinks about working with coding agents — developed firsthand in his personal
essay blog *Register Spill*. Where the `amp` Chronicle is team-authored,
product-anchored guide content, this is Ball's first-person reflection plus a
weekly "Joy & Curiosity" roundup that reads and comments on the wider field.
Material skews here (essays as practice writing — authorship triage,
agent-as-new-tool-category reframes, feedback-loop discipline); `artifacts/` is
expected to stay sparse. One concept per file; this index lists them, one line
each.

- [building-software-is-learning](./building-software-is-learning.md) — building something new is learning, not execution; the frame everything else hangs off.
- [reduce-time-to-feedback](./reduce-time-to-feedback.md) — the highest-leverage move: shrink the gap between "let me try" and reality.
- [verify-dont-read-every-line](./verify-dont-read-every-line.md) — test against your mental model; once verified, the code itself matters less.
- [paint-by-numbers-for-new-software](./paint-by-numbers-for-new-software.md) — supply the lines/numbers for new code, let the agent fill the colors.
- [where-is-the-knowledge](./where-is-the-knowledge.md) — agents succeed when task knowledge lives in prompt, codebase, or training data; gaps fail.
- [code-is-cheap-now](./code-is-cheap-now.md) — one constant changed in a fundamental equation; agents aren't ChatGPT copy-paste.
- [manage-attention-while-agents-run](./manage-attention-while-agents-run.md) — refuse the reflexive cmd-tab; steer or do your own work while the agent runs.
- [agents-as-async-functions](./agents-as-async-functions.md) — ephemeral sandboxes make agents async function calls, not remote controls; end prompts with the whole loop and switch away.
- [generate-variations-then-curate](./generate-variations-then-curate.md) — for fiddly, feel-your-way work, fan out into many variations and curate rather than hand-edit.
- [ungated-agents-are-tactical-tornadoes](./ungated-agents-are-tactical-tornadoes.md) — unmanaged agents can churn out working code that doesn't fit the system, piling up complexity debt faster than a human ever could.
- [agent-notifications-habituate-fast](./agent-notifications-habituate-fast.md) — broadcasting agent events to a shared channel becomes ignored wallpaper within days; filter, don't just tune.
- [recalibrate-bug-tolerance](./recalibrate-bug-tolerance.md) — agents shrink a shipped bug's lifetime, so the old speed-vs-defects balance point needs a deliberate reset, not a frozen assumption.
- [force-clarity-with-controlled-english](./force-clarity-with-controlled-english.md) — when an answer is jargon-heavy or vague, demand it restated in ASD-STE100 Simplified Technical English to expose whether it says anything.
