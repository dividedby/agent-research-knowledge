# Practices — maggieappleton

Maggie Appleton is a designer-developer building Ace (a multiplayer AI coding
workspace) and publishing firsthand essays on agent orchestration patterns,
design as the new bottleneck when implementation costs collapse, and the
sustainability of vibe-coded output. The additive vantage: the only practitioner
in the corpus writing from a UX/design angle about multi-agent coordination
failures and collaborative agent tooling — the engineering-focused harness
builders don't carry this perspective. Corpus-anchored via thorstenball "Joy &
Curiosity" roundups #71 and #83.

Material skews here (practices — agent orchestration, design bottleneck framing,
working-with-agents essays); `artifacts/` may receive harness-design decisions
from Ace's build as they are documented. One concept per file; this index lists
them, one line each.

- [design-is-the-new-bottleneck](./design-is-the-new-bottleneck.md) — when agents write all the code, design, planning, and taste become the limiting factor.
- [alignment-is-the-team-bottleneck](./alignment-is-the-team-bottleneck.md) — single-player agent tooling scales the wrong thing; agreeing *what* to build, not *how*, is the new constraint, and PRs/issues are the wrong primitives.
- [code-distance-is-contextual](./code-distance-is-contextual.md) — how far you step back from the code is an "it depends" dial (domain, feedback loops, risk, brownfield, team size, seniority), not a personality or moral stance.
- [vibe-coding-is-a-spectrum-of-understanding](./vibe-coding-is-a-spectrum-of-understanding.md) — vibe code = code nobody understands; a continuous comprehension axis, and the same tools can climb you back up it.
- [barefoot-developers](./barefoot-developers.md) — LLMs enable a new middle-tier builder of local home-cooked software, but the legos still need glue (orchestrator agents + agent-aware tools).
